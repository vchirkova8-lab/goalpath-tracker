# Техническое задание. Трекер целей «GoalPath» для коуч-практики

## 1. Основа заказа
Реальный заказ на бирже Weblancer (раздел «Мобильные приложения»):
«React Native-приложение для помощи людям с зависимостями — не просто
трекер привычек, а комплексная экосистема».
Для MVP ключевой контур экосистемы — трекер целей с этапами и дневником
настроения — реализуется как адаптивное веб-приложение. Мобильные
платформы, чат поддержки и интеграции — вне рамок MVP (этап 2).

## 2. Заказчик и продукт
- Клиент: коуч-практика по работе с целями и привычками «GoalPath».
- Продукт: личный трекер целей для подопечного коуча.
- Слоган: «Большая цель — это лестница из маленьких шагов».

## 3. Цель проекта
Дать подопечному коуча понятный инструмент: разбить большую цель на этапы,
видеть прогресс, фиксировать настроение и выгружать данные для разбора
на сессии с коучем.

## 4. Пользователи
- Подопечный (единственный пользователь MVP, вход не требуется —
  личный дневник на своём устройстве).
- Коуч — получает выгрузку данных от подопечного (этап 2 — кабинет коуча).

## 5. Экраны приложения
1. «Мои цели»: карточки целей с прогресс-баром, дедлайном и остатком дней;
   создание, редактирование и удаление цели.
2. Карточка цели (раскрытие): этапы-чеклисты с галочками, процент прогресса,
   отметка о завершении цели.
3. «Дневник»: записи настроения (шкала 1–5 + комментарий), добавление и
   удаление записей, хронология.
4. «Обзор»: статистика — активные и завершённые цели, выполнено этапов,
   среднее настроение за неделю; мотивационная плашка.
5. «Экспорт»: выгрузка всех данных в JSON-файл одним кликом.

## 6. Функциональные требования
- Хранение данных — в браузере (localStorage), без серверной части (MVP).
- Прогресс цели считается автоматически: выполненные этапы / все этапы.
- Когда все этапы выполнены — цель получает статус «Выполнено» и
  праздничное подтверждение.
- Дедлайн цели: отображается остаток дней; просроченные цели подсвечиваются.
- Настроение: шкала 1–5; среднее настроение за последние 7 дней.
- Экспорт JSON: файл цели + этапы + дневник скачивается целиком.
- Адаптивность: компьютер, планшет, смартфон.

## 7. Оформление
По брендбуку коуч-практики «GoalPath» (info/brandbook.txt): индиго и янтарь,
мягкие градиенты, логотип-ступени (info/logo.svg), дружелюбная типографика.

## 8. Критерии готовности MVP
1. Цель создаётся с этапами; прогресс считается автоматически.
2. Отметка этапа сохраняется; при 100% цель становится «Выполнено».
3. Дневник настроения пополняется; среднее за неделю считается.
4. Просроченные цели визуально выделяются.
5. Экспорт JSON скачивается и содержит все данные.
6. Интерфейс корректно работает на компьютере и смартфоне.
7. Данные не пропадают после обновления страницы.
8. Демо-данные: 3 цели (в работе / почти завершена / выполнена), записи дневника.
